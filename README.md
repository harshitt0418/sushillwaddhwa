# Sushill Waddhwa — A Private Access House

> **Global Hospitality · Private Access · Strategic Partnerships**

A bespoke, high-end digital experience crafted for **Sushill Waddhwa**, Global Hospitality Leader and Founder operating across luxury hotel buyouts, boutique hospitality development (*Artoso Hospitality Corp.*), prime real estate acquisitions, private aviation, and superyachts (*Platinum World Group / Platinum World Lifestyle*).

---

## 🏛️ Architectural Concept: "A Private Access House"

This project is built around the identity of a discreet international access house — curated, architectural, and relationship-led. It is not a booking engine or standard corporate agency site.

### Key Pages
1. **Home (`/`)**: Cinematic entrance, typographic manifesto, personal profile introduction, interactive capabilities horizontal showcase, verified metrics, featured venture (*Artoso Hospitality*), and discreet closing CTA.
2. **The Principal (`/about`)**: Executive profile, editorial bio, vertical 5-pillar career focus timeline, and venture ecosystem showcase.
3. **Private Access (`/private-access`)**: 5 immersive full-height capability tiers (Hotel Buyouts, Real Estate, Private Aviation, Yachts & Lifestyle, Boutique Hotel Development) and interactive global transit map.
4. **Contact (`/contact`)**: High-trust confidential dossier form with interactive submission protocol and direct executive coordinates.

## 🚀 Getting Started

### Prerequisites
* Node.js (v18+)
* npm / yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/harshitt0418/sushillwaddhwa.git

# Navigate to project directory
cd sushillwaddhwa

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
# Build optimized production bundle
npm run build

# Preview build locally
npm run preview
```
